# Climate Analyzer — Backend (API)

FastAPI + MongoDB API for the **Climate Hazard Trend Analyzer**: historical heatwave
frequency, duration and intensity for any city/state/bbox in India, computed from the
[Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api) archive.

This repository is the **backend slice** of the project monorepo, split out so it can be
deployed on [Render](https://render.com) as a Docker web service. The frontend lives separately
(Vercel): https://climate-analyzer-seven.vercel.app

---

## 1. Run locally

Prerequisites: Docker, Python 3.12.

```bash
# MongoDB 7 (single-node replica set)
docker run -d --name mongo -p 27017:27017 mongo:7.0 --replSet rs0 --bind_ip_all
docker exec mongo mongosh --quiet --eval 'rs.initiate({_id:"rs0",members:[{_id:0,host:"localhost:27017"}]})'

# API
pip install -e ".[dev]"
uvicorn app.main:app --reload          # http://localhost:8000

# Seed a demo region (offline, no provider calls — same script CI uses)
python scripts/seed_smoke_region.py

# Real region (live provider fetch)
python -m app.cli backfill --point 17.385,78.4867        # city point ≈ 6 s
python -m app.cli backfill --bbox 17.1,78.3,17.7,78.9    # 3×3 grid ≈ 4–5 min
```

Copy `.env.example` → `.env` for local values. Never commit real secrets.

## 2. Tests & lint

```bash
pip install -e ".[dev]"
ruff check . && ruff format --check .
pytest -q                       # unit + integration against TEST_MONGODB_URI

# API smoke (offline seed → 18 checks, no provider dependency)
REGION_ID=$(python scripts/seed_smoke_region.py)
uvicorn app.main:app --port 8000 &
node scripts/api-smoke.mjs http://127.0.0.1:8000 "$REGION_ID"
```

CI (`.github/workflows/ci.yml`) runs the same: ruff → pytest against a real Mongo replica set → API smoke.

## 3. API

Base path `/api/v1`, JSON only, every response carries `X-Trace-Id`. Interactive docs at `/docs`.

| Method | Path | Purpose | Rate limit |
|---|---|---|---|
| GET | `/healthz` | liveness (no DB) | none |
| GET | `/readyz` | readiness (Mongo ping + scheduler heartbeat) | none |
| GET | `/hazards` | hazard registry | 60/min |
| GET | `/regions/presets` | curated 25 cities + 12 states | 60/min |
| GET | `/regions/search?q=` | geocode proxy | 10/min |
| POST | `/regions` | register region (idempotent) → triggers backfill | 10/min |
| GET | `/regions/{region_id}` | status + coverage | 60/min |
| GET | `/analysis/timeseries` | annual series + 5-yr rolling mean | 60/min |
| GET | `/analysis/summary` | headline + trend stats | 60/min |
| GET | `/analysis/events` | paginated event list | 60/min |
| GET | `/analysis/inspect` | daily rows for one event | 60/min |
| POST | `/admin/recompute` | force recompute (`X-Admin-Token`) | 5/min |
| GET | `/admin/ingest-runs` | ingest audit (`X-Admin-Token`) | 30/min |
| POST | `/client-errors` | optional FE error beacon | 20/min |

Errors always use one envelope (`error.code`, `error.message`, `error.retryable`,
`error.retry_after_seconds`, `trace_id`) — stable machine codes such as `VALIDATION_ERROR` 422,
`RATE_LIMITED` 429, `REGION_NOT_READY` 409 (retryable), `TIMEOUT` 504 (safe to retry).

## 4. Environment variables

| Var | Default | Purpose |
|---|---|---|
| `MONGODB_URI` | `mongodb://localhost:27017` | DB connection (**secret** in prod) |
| `MONGODB_DB` | `climate_analyzer` | DB name |
| `ADMIN_API_TOKEN` | — | Admin bearer token (**secret**, `openssl rand -hex 32`) |
| `FRONTEND_ORIGIN` | `http://localhost:5173` | Exact CORS allowlist origin |
| `OPENMETEO_BASE_URL` / `GEOCODING_BASE_URL` | Open-Meteo endpoints | overridable for tests |
| `RATE_LIMIT_*`, `RESPONSE_CACHE_TTL_S`, `ONDEMAND_WAIT_SECONDS` | — | tuning knobs |
| `LOG_LEVEL` / `LOG_FORMAT` | `INFO` / `json` | logging |

## 5. Deploy on Render

`render.yaml` is a [Render Blueprint](https://render.com/docs/blueprint-spec): **New → Blueprint** →
connect this repo → Render reads the file (Docker runtime, `/readyz` health check, `autoDeploy`).

Env vars declared there:

| Var | Value |
|---|---|
| `MONGODB_URI` | MongoDB Atlas connection string (paste in the dashboard — `sync: false`) |
| `MONGODB_DB` | `climate_analyzer` |
| `ADMIN_API_TOKEN` | generated by Render (rotate: `openssl rand -hex 32`) |
| `FRONTEND_ORIGIN` | `https://climate-analyzer-seven.vercel.app` |
| `LOG_LEVEL` / `LOG_FORMAT` | `INFO` / `json` |

First boot ensures Mongo validators + indexes in `lifespan`; check `GET /healthz` → 200 and
`GET /readyz` → 200. Free tier sleeps after ~15 min idle (first request ≈ 60 s cold start).
Then set `VITE_API_BASE_URL` on Vercel to the Render URL and redeploy the frontend.
